🌸 BloomCare+

A Smart Maternal & Child Health Management System

📖 Overview

BloomCare+ is a mobile-based healthcare management system designed to support mothers, midwives, and doctors in managing maternal and child health services. The system replaces traditional manual health records with a secure, digital platform that improves accessibility, efficiency, and communication between mothers and healthcare providers.

Our goal is to provide real-time access to health data, appointment management and child growth tracking to enhance maternal and child healthcare services.

✨ Key Features
👩 Mothers

Digital maternal & child health records (replacing the MOH baby book)

Notifications for clinic visits, vaccinations, and appointments

Child growth tracking with graphs & milestones

Multilingual support for better accessibility

🧑‍⚕️ Midwives

Update mother & child health records

Schedule clinics, vaccinations, and preposition distributions

Send notifications/reminders to mothers

👨‍⚕️ Doctors

Access and review patient health records

Manage maternal and child health progress

Update treatment details

🛠️ Tech Stack

Frontend: Flutter (cross-platform mobile application)

Backend: Spring Boot (Java)

Database: MySQL

Notifications: Firebase Cloud Messaging (FCM)

Authentication: JWT (JSON Web Token)

📱 System Roles & Access

Mothers → Register using NIC & password

Midwives → Predefined login credentials

Doctors → Predefined login credentials

🚀 Installation & Setup
1. Clone the Repository
git clone https://github.com/your-repo/BloomCare-Plus.git
cd BloomCare-Plus

2. Backend Setup (Spring Boot)

Install Java 17+ and Maven

Update application.properties with MySQL & Firebase configurations

Run the backend:

mvn spring-boot:run

3. Database Setup

Install MySQL

Create a database:

CREATE DATABASE bloomcare;


Run migration scripts (if included)

4. Frontend Setup (Flutter)

Install Flutter SDK

Navigate to frontend/ and run:

flutter pub get
flutter run
